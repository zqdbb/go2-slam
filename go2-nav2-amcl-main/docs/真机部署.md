# Go2 真机部署（`real` 分支）

本分支保留 Mujoco/Gazebo 仿真；真机入口不会启动仿真器。真机运动由 Go2 机载 Sport Mode 官方步态执行，ROS 侧只发送限速后的速度请求。

Orin 当前为 Ubuntu 20.04/Foxy，Humble 建议运行 ARM64 Docker 容器，宿主机 Foxy/宇树驱动保持不变。Docker Hub 不可访问时需从联网机器导入镜像。

```bash
cd ~/go2-slam-real/go2-nav2-amcl-main
sudo docker build --network host -t go2-slam:humble-arm64 -f Dockerfile.arm64.humble .
./docker/run_real_container.sh bash
```

无网络时可在联网 ARM64 机器执行 `docker save go2-slam:humble-arm64 | gzip > go2-slam-humble-arm64.tar.gz`，传到 Orin 后执行 `gunzip -c go2-slam-humble-arm64.tar.gz | sudo docker load`。

## 控制机准备

Ubuntu 22.04、ROS 2 Humble，以及宇树官方 `unitree_ros2`/Cyclone DDS。先按官方脚本配置连接 Go2 的有线网卡，再执行：

```bash
source /opt/ros/humble/setup.bash
source ~/unitree_ros2/cyclonedds_ws/install/setup.bash
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
cd ~/桌面/go2/go2-nav2-amcl-main
colcon build --symlink-install
source install/setup.bash
```

## 上电后的只读检查

```bash
bash tools/go2_real_preflight.sh
ros2 topic echo /lf/sportmodestate --once
ros2 topic echo /utlidar/robot_pose --once
```

若官方版本使用 `/utlidar/cloud` 而不是 `/utlidar/cloud_deskewed`，启动时覆盖：

```bash
ros2 launch go2_core go2_real_slam.launch.py input_topic:=/utlidar/cloud
```

## 建图

```bash
ros2 launch go2_core go2_real_slam.launch.py
ros2 run teleop_twist_keyboard teleop_twist_keyboard
ros2 run nav2_map_server map_saver_cli -f ~/go2_maps/site_map
```

## 已有地图导航

悬空测试确认话题和 TF 正常后，再让狗落地：

```bash
ros2 launch go2_navigation2 go2_real_nav.launch.py \
  map:=~/go2_maps/site_map.yaml
```

在 RViz 先执行 `2D Pose Estimate`，再发送 `Nav2 Goal`。默认真机速度限制为：前进 0.35 m/s、侧移 0.20 m/s、旋转 0.80 rad/s；超过 0.5 s 没有新速度指令会自动发送站立指令。

## 安全要求

首次测试必须抬起四足或在空旷区域进行；始终保留遥控器急停权限。确认 `/odom -> base_link` 和雷达 TF 后再启用 Nav2。雷达安装偏移可在 `go2_driver/params/driver.yaml` 调整，不能凭仿真参数直接假设。
